# ComfyUI 通知适配报告

## 1. 适配范围

把 ComfyUI 工作流通知接入 TapRelay，使手机端弹窗正确显示官方名称与图标，而不是回退为“其他”。

ComfyUI 通知通过 HTTP `POST http://localhost:1122/send` 携带 `source=comfyui` 到达，例如：

```powershell
curl.exe -s -X POST http://localhost:1122/send -H "Content-Type: application/json" -d "{\"message\":\"ComfyUI 工作流已完成\",\"source\":\"comfyui\",\"status\":\"completed\"}"
```

## 2. 名称与图标来源

- 名称统一使用官方项目名 **ComfyUI**（`Comfy-Org/ComfyUI`）。
- 图标取自官方仓库 `Comfy-Org/ComfyUI_frontend` 的 `apps/website/public/apple-touch-icon.png`（官方深紫底 + 霓虹黄 `#F2FF59` 品牌标），缩放到 `256x256 PNG`。
- 禁止使用第三方改版（如 ComfyNexus）的名称或图标。

- 官方 Logo：`pc-app/Assets/ic_comfyui_logo.png`、`android-app/app/src/main/res/drawable-nodpi/ic_comfyui_logo.png`。

## 5. 说明

ComfyUI 属于 HTTP 触发的通用通知来源，不依赖本地进程/日志监控，PC 端无需新增进程别名。`comfyui` 渠道键在 PC、Android 与 Node 服务三端均作为内置保留键，避免被当成未知应用重复注册。

## 6. 任务日志：K 采样器正向提示词（2026-08-22 增强）

原实现手机卡片只显示笼统的“工作流已完成”。现增强为：**识别工作流中 K 采样器（KSampler / KSamplerAdvanced）的正向提示词作为任务日志展示**。

- 触发节点（ComfyUI-GuliNodes）可在 `/send` 请求中**可选**携带 `prompt` 字段（ComfyUI 执行 prompt 图，即节点 id → 节点定义），例如：

```powershell
$graph = @{
  "1" = @{ class_type = "KSampler"; inputs = @{ positive = @("2", 0); negative = @("3", 0) } }
  "2" = @{ class_type = "CLIPTextEncode"; inputs = @{ text = "a cinematic cyberpunk samurai, neon city" } }
  "3" = @{ class_type = "CLIPTextEncode"; inputs = @{ text = "blurry, low quality" } }
} | ConvertTo-Json -Depth 10 -Compress
curl.exe -s -X POST http://localhost:1122/send -H "Content-Type: application/json" -d "{`"message`":`"ComfyUI 工作流已完成`",`"source`":`"comfyui`",`"status`":`"completed`",`"prompt`":$graph}"
```

- PC 端 `pc-app/ComfyUIPromptParser.cs` 从 `prompt` 图里定位 K 采样器节点的 `inputs.positive`（支持 `["<节点id>", 0]` 引用或内联字符串），跟随引用到 `CLIPTextEncode.inputs.text` 取出正向提示词，经 `taskLog` 字段随广播下发（正文上限 4000 字符）。
- Android 端 `NotifyMessage.taskLog` 承载该正文并随 `LocalStore` 持久化；`displayContent()` 在 `taskLog` 非空时用它作为卡片正文（通知栏、悬浮卡、主界面统一生效），否则回退到 `content` 原文。
- **不传 `prompt` 时行为不变**：手机仍显示原来的 `message` 正文，向后兼容。
- 注意：`/send` 请求体受 64KB 上限约束，若工作流图很大，建议只携带精简后的 prompt（不含节点坐标）或直接传正向提示词文本。
