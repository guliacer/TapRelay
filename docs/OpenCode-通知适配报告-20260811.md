# OpenCode 通知适配报告

## 1. 适配范围

把本地 OpenCode（`opencode-ai`，桌面版 Electron + CLI 共用同一 SQLite 数据库）的任务状态通知接入 TapRelay，使手机端弹窗正确显示官方名称与图标，而不是回退为“其他”。

OpenCode 与 Claude/ChatGPT/Trae 等智能体不同，它把会话与消息持久化在本地 SQLite（`~/.local/share/opencode/opencode.db`），因此采用与百度网盘/夸克网盘相同的“数据库变更事件驱动”监控，而非 Hook 或日志文件流。

## 2. 信号来源与状态映射

- 数据来源：`~/.local/share/opencode/opencode.db`（WAL 模式），`message` 表 `data` 列 JSON 内 `role=assistant` 的消息。
- 完成信号：`finish == "stop"` 且无 `error` → `status=completed`。
- 失败信号：存在 `error.name`（如 `APIError`，如欠费 401、崩溃）→ `status=failed`，正文取 `error.message`。
- 用户取消：`error.name == "MessageAbortedError"` → `status=cancelled`，**静默忽略**，不误报失败。
- `finish == "tool-calls"` 等中间态 → 不触发，等待终态。
- 项目目录：从消息所属 `session.directory` 读取，作为 `cwd`；`projectName` 由 `ProjectNameResolver.ResolveFolderFirst` 取目录叶名。
- 去重：以 `messageId|status` 为键，同一消息的同一终态只通知一次；监控器从启动时读取的 `MAX(time.created)` 基线开始，不重放历史完成记录。

## 3. 名称与图标来源

- 名称统一使用官方产品名 **OpenCode**（`appKey=opencode`）。
- 图标取自官方桌面版安装目录 `%LOCALAPPDATA%\Programs\@opencode-aidesktop\resources\app.asar` 内 `\resources\icons\ios\AppIcon-512@2x.png`（官方 512×512 Logo），缩放到 `256x256 PNG`。
- 品牌色取自官方 Logo 的浅灰白 `#F4F4F5`。

## 4. 项目集成

- 官方 Logo：`pc-app/Assets/ic_opencode_logo.png`、`android-app/app/src/main/res/drawable-nodpi/ic_opencode_logo.png`。
- Android 通知小图标：`android-app/app/src/main/res/drawable-nodpi/ic_stat_opencode.png`。
- Android 渠道、来源归一化、图标与品牌色：`data/Channel.kt`、`ui/ChannelIcon.kt`、`ui/theme/Color.kt`、`notification/NotificationHelper.kt`（复用共享任务通知渠道 `task_alerts_v3`）。
- PC 监控器：`pc-app/OpenCodeMonitor.cs`（新增，数据库变更事件驱动 + 15s 进程恢复轮询 + 5min 重新发现）。
- PC 面板图标与品牌色：`pc-app/NotificationAppsPanel.cs`、`pc-app/NotificationAppRegistry.cs`（`opencode` 列为内置保留键）。
- PC 进程别名与启动门控：`pc-app/AdaptedProcessGate.cs`（`opencode` → `OpenCode` 进程名）。
- PC 目录元数据：`pc-app/AppCatalogMetadata.cs`、`pc-app/AgentCompletionMonitor.cs`（集成 OpenCodeMonitor 并派发 `source=opencode`）。
- 手机继续会话：`agent.call` 的 `session.send` 由 PC 通过 `opencode run --session <sessionId> <message>` 执行；`opencode session` 仅支持会话 list/delete，不能用于发送文本。
- Node 通知服务保留键：`notify-server/src/apps.js`（`opencode` 列为内置来源）。
- 安装路径覆盖：`TAPRELAY_OPENCODE_DB` 环境变量可指定数据库文件。

## 6. 说明

- `opencode` 为内置保留键，与 `claude`/`codex`/`comfyui` 一致，不通过 `/apps/register` 注册（避免被当成未知应用重复注册或覆盖内置元数据）。
- OpenCode 数据库与桌面版进程（`OpenCode.exe`）绑定：监控器仅在 OpenCode 运行时启用通知，进程退出自动暂停、重启自动恢复。
- 用户主动停止（`MessageAbortedError`）映射为取消并静默，符合“不把用户取消误报为失败”的适配约束。
