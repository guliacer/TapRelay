# 技术栈与核心库

## 适用范围
本文件适用于 `W:\TapRelay\pc-app` 的 PC 桌面端、`W:\TapRelay\notify-server` 的 Node.js 协议测试服务、`W:\TapRelay\android-app` 的 Android 客户端，以及测试、构建、依赖锁定策略。

## 规则条目

### R1: Node.js 版本与 npm 锁定
**断言**：服务端必须使用本机可用的 Node.js `24.13.0` 与 npm `11.6.2`；`W:\TapRelay\notify-server\package.json` 必须声明 `packageManager: "npm@11.6.2"`，并提交 `W:\TapRelay\notify-server\package-lock.json`。
**示例**：
```json
{
  "name": "notify-server",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "packageManager": "npm@11.6.2",
  "engines": {
    "node": "24.13.0",
    "npm": "11.6.2"
  }
}
```
**违规特征**：使用 `pnpm-lock.yaml`、`yarn.lock` 或未提交 `package-lock.json`；把 `engines.node` 写成 `>=18`、`latest` 或空缺。

### R2: 服务端核心依赖固定
**断言**：`notify-server` 运行时只允许依赖 `ws` `8.21.1` 与 Node.js `24.13.0` 内置模块；默认不得引入 Express、Koa、Fastify、Socket.IO 或数据库驱动。
**示例**：
```json
{
  "dependencies": {
    "ws": "8.21.1"
  },
  "devDependencies": {
    "vitest": "4.1.10"
  }
}
```
**违规特征**：`package.json` 出现 `"express"`、`"socket.io"`、`"mongoose"`、`"sqlite3"`；`ws` 版本写成 `^8.21.1`、`latest` 或 `8.x`。

### R3: 服务端测试框架固定
**断言**：服务端测试必须使用 `vitest` `4.1.10`；测试文件必须放在 `W:\TapRelay\notify-server\test\*.test.js`，测试命令必须是 `npm test`。
**示例**：
```json
{
  "scripts": {
    "start": "node server.js",
    "test": "vitest run"
  }
}
```
**违规特征**：引入 Jest/Mocha/Ava；把测试文件放到项目根目录；只提供手动 curl 验证而没有 `npm test`。

### R4: Android 构建版本固定
**断言**：Android 项目必须使用 Gradle Wrapper `9.6.1`、Android Gradle Plugin `9.3.1`、AGP 9 内置 Kotlin 支持、Kotlin Compose compiler plugin `2.4.10`、JDK `21.0.4`、compileSdk `36`、targetSdk `36`、minSdk `26`；不得依赖全局 `gradle` 命令，不得显式应用 `org.jetbrains.kotlin.android`。
**示例**：
```properties
# W:\TapRelay\android-app\gradle\wrapper\gradle-wrapper.properties
distributionUrl=https\://services.gradle.org/distributions/gradle-9.6.1-bin.zip
```
```kotlin
// W:\TapRelay\android-app\build.gradle.kts
plugins {
    id("com.android.application") version "9.3.1" apply false
    id("org.jetbrains.kotlin.plugin.compose") version "2.4.10" apply false
}
```
**违规特征**：要求用户安装全局 Gradle；`build.gradle.kts` 中插件版本为空、使用 `+` 或使用 alpha/beta 版本；`compileSdk` 不是 `36`；`plugins` 中出现 `id("org.jetbrains.kotlin.android")`。

**构建入口**：使用 `tools/test-android.ps1`，通过 `-JavaHome` 或有效的 `JAVA_HOME` 指定 JDK 21.0.4；本机可使用已校验的 `.gradle-user/jdks/jdk-21.0.4+7` 缓存。脚本必须先验证 JDK 版本再调用 Wrapper，禁止把 Java 17 的成功构建记为 JDK 21.0.4 验收。

### R5: Android 依赖版本固定
**断言**：Android 客户端必须使用 Jetpack Compose BOM `2026.06.01`、OkHttp `5.4.0`、`androidx.lifecycle:lifecycle-service` `2.10.0`、`androidx.core:core-ktx` `1.18.0`、`androidx.activity:activity-compose` `1.12.4`、`org.jetbrains.kotlinx:kotlinx-coroutines-android` `1.11.0`；Compose 组件版本必须由 BOM 管理，并且依赖不得要求高于本机已安装 `compileSdk 36`。
**示例**：
```kotlin
dependencies {
    implementation(platform("androidx.compose:compose-bom:2026.06.01"))
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.material3:material3")
    implementation("androidx.activity:activity-compose:1.12.4")
    implementation("androidx.lifecycle:lifecycle-service:2.10.0")
    implementation("androidx.core:core-ktx:1.18.0")
    implementation("com.squareup.okhttp3:okhttp:5.4.0")
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.11.0")
    testImplementation("junit:junit:4.13.2")
    androidTestImplementation("androidx.compose.ui:ui-test-junit4")
}
```
**违规特征**：OkHttp 版本仍写 `4.12.0`；Compose 依赖手写单独版本；引入 Retrofit、Room、Hilt、Navigation 等未被规则允许的库。

### R6: PC 桌面端技术栈固定
**断言**：PC 端正式入口必须使用本机可用的 .NET SDK `3.1.426`、`Microsoft.WindowsDesktop.App` `3.1.32`、WinForms 与 `Microsoft.AspNetCore.App` `3.1.32`；项目文件必须位于 `W:\TapRelay\pc-app\TapRelay.csproj`，目标框架必须是 `netcoreapp3.1`，不得引入 Electron、Tauri、WPF 或第三方托盘库。
**示例**：
```xml
<!-- W:\TapRelay\pc-app\TapRelay.csproj -->
<Project Sdk="Microsoft.NET.Sdk.WindowsDesktop">
  <PropertyGroup>
    <OutputType>WinExe</OutputType>
    <TargetFramework>netcoreapp3.1</TargetFramework>
    <UseWindowsForms>true</UseWindowsForms>
  </PropertyGroup>
  <ItemGroup>
    <FrameworkReference Include="Microsoft.AspNetCore.App" />
  </ItemGroup>
</Project>
```
**违规特征**：新增 `package.json` 作为 PC GUI；要求安装 Electron；PC 端入口仍依赖 `notify-server\start.bat`；使用 `net8.0-windows` 但本机没有对应 SDK。
