# Android 移动工作台统一界面设计

日期：2026-10-30  
范围：`android-app` 的首页、ComfyUI、设备管理、权限引导、个人项目入口与全局主题

## 1. 目标

把现有 Android 端整理成一个统一的移动工作台，让用户在单手操作时能快速完成三条主路径：

1. 查看任务通知、未读消息和等待处理项。
2. 选择 ComfyUI 工作流、填写参数、运行并查看结果。
3. 查看/修复 PC 连接、管理设备和处理系统权限。

现有通知、连接、权限、ComfyUI、个人项目和主题能力继续保留。数据来源继续使用现有 `MessageRepository`、`ComfyUiRepository` 和本地 Store，不借此任务引入账号、云端服务或新的网络端口。

## 2. 非目标

- 不重写 WebSocket、通知解析、ComfyUI API 或图片缓存协议。
- 不新增 Android 第三方 UI 框架或导航依赖；使用现有 Jetpack Compose Material 3。
- 不把个人项目、主题切换等低频功能提升为底部一级入口。
- 不在本轮引入横屏双栏编辑器；先保证窄屏手机和 MuMu 竖屏体验。

## 3. 总体信息架构

应用采用一个类似微信底栏的持久三入口工作台壳层。底栏固定在主页面底部，用户点击任意入口后立即切换到对应页面；三个页面不是弹窗，也不通过顶部图标串联。

| 一级入口 | 主要任务 | 页面状态 |
| --- | --- | --- |
| 任务 | 连接摘要、消息历史、未读和等待处理 | 消息列表模式、滚动位置、弹层 |
| ComfyUI | 工作流列表、参数、运行状态、生成结果 | 当前工作流、参数、结果预览 |
| 设备 | 连接地址、连接动作、权限、PC 控制 | 地址历史、脱敏状态、设置项 |

底部导航只显示这三个入口，当前入口使用鼠尾草绿高亮和文字标签；每个入口都有 48dp 以上的触控区域。点击入口后，内容区立即替换为对应页面，底栏保持可见且不重新启动整个 Activity。三个页面各自保留最近状态：任务页保留列表模式和滚动位置，ComfyUI 保留当前工作流、参数和结果页，设备页保留表单与设置状态。首次启动的权限引导仍然是全屏流程，不显示底部导航。大图预览、前后对比和图片编辑器继续使用独立全屏弹层。

`MainActivity` 负责保存当前一级入口和各入口的返回状态，页面 Composable 负责展示内容。底栏切换只改变内容区的当前页面，不清空其他入口的页面状态。系统返回优先关闭弹层，其次回到任务页，再退出 Activity；在主页面之间不模拟连续的“返回上一级”跳转。

## 4. 统一视觉系统

### 4.1 颜色和层级

- 延续现有浅色/深色鼠尾草绿主题与 `AppColors` 语义色。
- 页面背景使用 `Background`，主要容器使用 `Surface`，次级容器使用 `PrimarySageSoft` 或主题对应的低对比表面。
- 连接状态、任务状态和错误状态只使用语义色胶囊/边条，不再给整张卡片铺满状态色。
- 所有自定义卡片、按钮和输入框的边框从 `BorderSoft` 取值，避免各页面自行定义相近灰色。

### 4.2 间距和形状

- 页面左右内边距统一为 16dp，主要分组间距 20dp，卡片内边距 16dp。
- 普通卡片圆角 16dp，紧凑标签圆角 999dp，弹层沿用 Material 3 的大圆角。
- 重要操作的最小触控高度为 48dp；紧凑操作仍保留不小于 40dp 的点击区域。
- 顶部和底部使用 edge-to-edge 安全区，内容不遮挡系统状态栏和导航栏。

### 4.3 文字层级

- 页面标题使用 `headlineSmall` 或 `titleLarge`。
- 分组标题使用 `titleMedium`，说明文字使用 `bodySmall`/`labelMedium`。
- 状态和时间信息使用 `labelMedium`，不使用过小的自定义字号承载关键语义。
- 长标题统一单行省略；详细内容在卡片内按需展开，不让按钮被长文本挤出屏幕。

## 5. 任务页设计

任务页承担首页主路径，首屏从上到下为：

1. **连接摘要卡**：显示设备名称、连接状态、当前 PC 地址是否脱敏，以及一个主动作。断开/重连时直接提供“重新连接”和“扫码连接”；已连接时主动作是进入设备页。
2. **消息分组标题**：显示“消息历史”、未读数量和列表模式切换。清空、全部已读等低频操作放入紧凑操作区，不与主标题争夺视觉重点。
3. **消息时间线**：保持现有按时间/项目两种模式、审批动作、等待状态和展开行为。卡片统一使用状态边条、来源图标、标题、时间和正文层级。
4. **空状态**：无消息时展示连接引导和扫码连接动作，避免只显示“暂无消息”。

任务页不再把 ComfyUI、个人项目和主题切换与消息列表并列在顶部。主题、权限、个人项目通过顶栏“更多”菜单进入；ComfyUI 通过底部导航进入。任务页、ComfyUI 页和设备页都直接作为底栏的三个可切换页面渲染。

## 6. ComfyUI 页面设计

保留当前工作流导入、导出、删除、置顶排序、参数固定、图片上传/蒙版、运行、结果接收、保存、素言转发和前后对比能力，重新整理呈现顺序：

1. **工作流选择状态**：顶栏显示 ComfyUI 和连接状态；工作流列表分为“置顶”和“全部”，卡片展示名称、最近运行状态和最近结果缩略图。
2. **参数编辑状态**：顶部显示当前工作流名称和返回工作流列表动作；“运行工作流”作为首个高优先级卡片，常用参数在前，固定参数和其余参数折叠在后。
3. **运行状态**：保留不确定进度条、脉冲状态胶囊、耗时和禁用态；运行中禁止重复提交，并保留返回查看列表的能力。
4. **结果状态**：结果卡片优先展示缩略图，其次展示文件名、尺寸、耗时和操作；单图/多图、前后对比、保存到 `Download/ComfyUI`、发送到素言等动作统一为同一套底部操作布局。
5. **失败和空状态**：网络失败、工作流缺失、无结果、缓存缺失分别给出原因和可执行的重试/返回动作。

当前 ComfyUI 页面内部的大量业务状态先不拆成新的数据层，优先通过页面壳层、分组卡片和状态组件复用现有逻辑，降低回归风险。

## 7. 设备页设计

将当前设备管理底部面板提升为底部导航中的完整页面；原有底部面板内容抽取为可复用分组，必要时保留从任务页打开的快速面板入口。通过底栏切换到设备页时，页面展示设备管理内容而不是再次弹出底部面板。

页面分组如下：

- **设备信息**：设备名称、PC 地址、扫码更新、历史地址。
- **连接管理**：当前通道状态、连接/断开/重连、脱敏切换。
- **系统能力**：权限检测、自动启动、动态效果等低频开关。
- **PC 控制**：休眠、关机等危险动作单独放在带确认的区域。

脱敏状态下输入框保持只读，复制和二维码继续使用真实地址；地址历史只展示脱敏后的内容。所有危险动作都显示明确的二次确认和执行结果。

## 8. 权限引导和低频入口

首次使用保持全屏权限向导，但改为“说明头部 + 待处理权限优先 + 已完成项折叠”的结构：

- 顶部说明通知送达、悬浮展示和后台保活分别需要什么权限。
- 未授权项显示“去设置”，已授权项显示完成状态和“管理”。
- 底部提供“开始使用/稍后处理”，返回后自动刷新。

非首次使用的权限检测复用同一内容组件，以设备页的独立页面展示。

个人项目和主题切换通过顶栏更多菜单打开，个人项目保持现有可滚动卡片和 GitHub 操作，不改变项目数据。

## 9. 状态、错误和可访问性

- 页面加载使用局部骨架或进度指示，不用整页闪烁。
- 网络错误必须说明当前页面、失败原因和下一步动作；重试按钮保持幂等。
- 连接状态、任务状态不能只靠颜色表达，必须同时有文字或图标。
- 所有图标按钮提供 contentDescription；底部导航、状态胶囊和卡片操作支持 TalkBack 顺序。
- 页面在 360dp 宽度下不出现横向溢出；长工作流名、地址和日志遵循省略/滚动规则。
- 深色模式沿用现有语义色，重点检查状态胶囊、按钮、输入框和全屏图片预览的对比度。

## 10. 验证方案

实现后使用 MuMu 模拟器进行实机验证，至少覆盖：

1. 首次启动权限引导、跳过、从设备页重新进入权限检测。
2. 无连接、连接中、已连接、断开和重连首页状态。
3. 空消息、未读消息、审批/等待消息、时间/项目两种列表模式和返回顶部。
4. ComfyUI 工作流列表、参数填写、上传图片、运行中、成功结果、失败重试、结果保存和全屏预览。
5. 设备页的地址脱敏、历史地址、扫码入口、PC 控制确认和主题切换。
6. 浅色/深色主题、360dp 窄屏、MuMu 默认分辨率和系统返回键。

当前电脑尚未检测到 MuMu 安装或 ADB 设备；在模拟器可用前，只能完成源码审查和构建检查，不能把模拟器截图或点击结果作为通过证据。

## 11. 验收标准

- 三个一级入口始终通过微信式底栏可达；点击底栏入口立即展示对应页面，切换不丢失任务列表滚动、ComfyUI 编辑或设备表单状态。
- 首页首屏能同时看见连接结果和消息历史入口，低频操作不挤占主路径。
- 任务、设备、ComfyUI、权限引导使用同一套颜色、间距、卡片、按钮和状态语义。
- 既有消息、连接、权限、PC 控制和 ComfyUI 功能保持可用，无新增端口或网络链路。
- MuMu 上完成第 10 节场景验证，记录构建版本、设备分辨率和关键截图。
