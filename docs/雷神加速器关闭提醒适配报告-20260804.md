# 雷神加速器关闭提醒适配报告

## 1. 可行性结论

可实现，且已在当前 Windows 环境完成适配和实测。适配目标为 `C:\Program Files (x86)\LeiGod_Acc`，规则已通过 GitHub 远程目录下发，TapRelay PC 端无需重新覆盖安装即可加载规则更新；Android 端沿用已有通知接收、持久化和安全跳转链路。

核心前提：TapRelay PC 进程持续运行，能够读取雷神进程路径和命令行，手机通知权限已开启且 PC 与手机 WebSocket 链路可用。雷神小程序跳转地址必须使用雷神官方确认的 `https://` 或 `weixin://` 地址；当前未从雷神安装包确认可靠官方深链，因此规则中的 `actionUrl` 暂留空，并支持通过 `TAPRELAY_LEIGOD_MINIPROGRAM_URL` 配置。

## 2. 技术实现路径

- 规则匹配：`imageNames=["leigod.exe"]`，`installRoots=["%PROGRAMFILES(X86)%\\LeiGod_Acc"]`，运行时展开并执行路径边界校验，避免其他目录的同名进程误触发。
- 雷神运行逻辑：雷神是 Electron 多进程应用。`leigod.exe -launch ...` 作为实际客户端窗口进程；无参数引导进程、`leigod_launcher.exe` 和 `leigod.exe --type=...` 的 GPU、Renderer、Utility、Crashpad 子进程均不作为主客户端触发源。规则使用 `lifecycleMode=leigod-client` 实现该过滤。
- 正常退出：WMI `Win32_ProcessStartTrace/StopTrace` 记录 PID、启动时间、路径和进程组；主窗口通过 `EnumWindows + GetWindowThreadProcessId + IsWindowVisible` 观察。主窗口曾可见后消失时触发 `reason=window-closed`；客户端进程随后退出时由停止事件兜底。
- 强制结束：处理 `Win32_ProcessStopTrace`，并以 `appKey + installRoot` 聚合 Electron 进程组；仅进程组最后结束时发送一次提醒。2 秒扫描用于补齐 WMI 漏事件和 TapRelay 启动前已经运行的客户端。
- 关机/重启：监听 Windows `SessionEnding`，对仍被观察的进程组尽早发送一次提醒；停止事件到达后通过会话状态和进程组去重，避免重复发送。
- 通知触发：只处理已匹配、已观察且尚未发送过的客户端关闭事件，发送 `status=waiting`。标题固定为 `雷神加速器关闭提醒`，正文固定为 `您已关闭雷神加速器客户端，请前往雷神小程序确认是否已关闭加速服务，避免闲置消耗时长`。
- 小程序跳转：通知携带可选 `actionUrl`；Android 端只允许 `https` 和 `weixin` scheme，点击前标记已读，再交给系统打开。未配置深链时仍正常送达通知，不会阻断提醒。
- 远程更新：目录地址为 `https://github.com/guliacer/TapRelay-remote-adapter-test/raw/refs/heads/main/catalog.json`。目录版本 `2026.08.04.5` 已包含雷神规则；PC 端按内容哈希检测并热替换规则，GitHub 分支目录请求使用 `no-cache`，避免旧 ETag 返回错误 `304` 导致规则不更新。

## 3. 对标适配方案

雷神与 ZCode、豆包共用 PC 端事件采集、统一 `NotifyServer` 推送、Android 端按 `source/status/taskId` 接收和持久化的规范。差异与调整如下：

- ZCode、豆包依赖任务日志或网络事件判断完成/失败；雷神没有稳定的关闭日志信号，因此改用客户端窗口状态和进程生命周期判断关闭。
- 雷神采用固定安装根目录和 Electron 主客户端命令行过滤，不能只按 `leigod.exe` 文件名监听。
- 规则更新仍为声明式数据，标题、正文、路径、生命周期模式和跳转地址均由远程目录提供；规则热替换会清空旧跟踪状态并按新规则重新扫描，已运行客户端也能立即使用新规则。
- 远程规则可以更新已有适配软件的匹配参数和文案，不需要重新覆盖安装 APK；若未来新增代码级监听能力，仍需要先升级一次 PC 程序，再由后续规则热更新覆盖数据变化。

## 4. 潜在风险与注意事项

- 权限：不要求修改雷神安装目录或注入雷神进程；WMI/进程路径读取若被系统策略拒绝，会主动放弃不确定的匹配，避免误提醒。TapRelay 本身必须保持运行。
- 关闭场景：正常退出、任务管理器强制结束和进程扫描兜底均已覆盖；关机/重启依赖 Windows 会话结束事件和有限的退出时间，网络异常时可能只能在 PC 侧记录而不能即时到达手机。
- 误触发：只接受目标安装根目录、`-launch` 主进程和已可见过的顶层窗口，并按进程组去重。若雷神未来把“关闭窗口”改为仅隐藏到托盘而不代表客户端退出，Windows 层面无法完全区分，仍可能按窗口消失触发提醒；需结合雷神官方退出信号再细化。
- 小程序地址：当前 `actionUrl` 为空，不猜测或放行任意 Intent。拿到官方小程序链接后，只需更新 GitHub 规则即可热生效。
- 原应用影响：适配只读进程信息和窗口信息，不修改雷神文件、配置、网络或服务，不主动结束雷神进程。
